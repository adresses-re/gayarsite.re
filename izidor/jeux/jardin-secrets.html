Les fleurs du secret

Clique les bonnes fleurs pour aider Ti Malo à retrouver les indices cachés dans le jardin de La Réunion.

Jouer Retour au menu

Principe

Trois bonnes fleurs révèlent le mot secret. Les autres sont des faux indices.

🌼 🌸 🌺 🌻 🌷 🍃

Astuce : les bonnes fleurs sont celles qui brillent dans le jardin.

Indice secret

Le mot à trouver peut être : partage.

Pourquoi ce jeu ?

C’est un mini-jeu maison très léger, parfait pour un site enfant et facile à garder sur GitHub Pages.
